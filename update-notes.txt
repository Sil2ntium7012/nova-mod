새 기능 창고 미리보기(너굴마을): 창고 목록이나 창고 안에서 기억해 둔 창고를 모두 펼쳐 보여 줘요. 보고 있는 창고만 밝게, 판을 누르면 그 창고로, 우클릭으로 창고 이름 정하기
새 기능 낚시 키 화살표(너굴마을, 선택): 낚시 미니게임의 W A S D 키캡을 같은 모양의 화살표로 보여 줘요
새 기능 레벨업 알림(너굴마을): 레벨업 조건을 채우면 소리와 함께 화면에 크게 알려 줘요
작물 캐기 모드: 넘친 씨앗을 너굴마을 쓰레기통으로 버려요(던지면 다시 주워지던 문제 수정). 정리 키를 누르면 씨앗은 한 칸만 남기고 빈칸을 벼나 밀로 채워요
마우스 잔상이 커서 기능으로 바뀌었어요: 커서를 직접 그려서 쓸 수 있고 잔상은 따로 켜고 꺼요
배경 그리기: 되돌리기와 앞으로 가기, HUD 상자 바깥까지 그리기, 선택해서 옮기기와 지우기, 복사해서 다른 기능 배경에 붙여넣기
인벤토리 탭: 기본 꺼짐으로 바뀌었어요(켜 두었던 설정도 한 번 꺼져요). 내 인벤토리에서는 안 뜨고, 옆 상자는 상자 칸만 보이며 상자 창만 끌어서 넘겨요
탭리스트가 기본 꺼짐으로 바뀌었어요
너굴 추천 체크: 다른 사람이 추천하거나 채팅에 추천 얘기가 나와도 완료로 뜨던 문제 수정
아이템 획득 HUD 크기를 바꾸면 위치가 어긋나던 문제 수정
시간 고정을 꺼도 게임을 다시 켤 때까지 고정 시간이 남던 문제 수정
다른 사람의 날개, 가방, 모자, 발자취, 망토 정보를 덜 자주 불러오게 바꿔 서버 부담을 줄였어요
